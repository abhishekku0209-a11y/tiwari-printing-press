# Tiwari Printing Press

## Current State
- Hero section uses a hardcoded image path (`/assets/1775225126583-019d5774-878d-74f4-8dea-f1ee68ec8c8a.png`) set directly in `Hero.tsx`.
- Admin dashboard has no way to change the hero background image.
- Motoko backend has blob storage for gallery images but no hero image field.
- All other visitors see the same hardcoded image; admin cannot change it.

## Requested Changes (Diff)

### Add
- Backend: `stable var heroImageBlobHash : Text` — stores the blob hash of the current hero image.
- Backend: `getHeroImageHash()` query — returns the current hero image blob hash (or empty string).
- Backend: `setHeroImageHash(adminData, blobHash)` update — admin sets the hero image blob hash.
- Frontend (Hero.tsx): On mount, fetch hero image hash from backend. If set, build blob gateway URL and use as background. If not set, fall back to the existing local asset path.
- Frontend (SettingsManagement.tsx): Add a "Hero Background Image" card with upload button, preview of current hero image, and a "Set as Hero Image" action that uploads to blob storage and calls `setHeroImageHash`.

### Modify
- `src/backend/main.mo`: Add `heroImageBlobHash` stable variable and two public functions (`getHeroImageHash`, `setHeroImageHash`).
- `src/frontend/src/components/Hero.tsx`: Load hero image URL dynamically from backend instead of hardcoded path.
- `src/frontend/src/pages/admin/sections/SettingsManagement.tsx`: Add hero image upload section at the top.
- `src/frontend/src/declarations/backend.did.d.ts` and `.did.js`: Regenerated by backend codegen to include new functions.

### Remove
- Nothing removed; hardcoded image path kept as fallback only.

## Implementation Plan
1. Update `main.mo` — add `heroImageBlobHash` stable var, `getHeroImageHash` query, `setHeroImageHash` shared update.
2. Update `Hero.tsx` — fetch hash on mount via `createActorWithConfig`, build URL via `StorageClient.getDirectURL`, use as background. Fallback to local asset while loading or if empty.
3. Update `SettingsManagement.tsx` — add hero image section: file input, preview, progress bar, upload button that uses `StorageClient.putFile` then calls `setHeroImageHash`.
4. Run validation (lint + typecheck + build) and fix errors.
5. Deploy.
